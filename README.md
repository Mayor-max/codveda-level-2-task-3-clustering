# Codveda Technologies Data Science Internship

# Level 2 – Task 3: Clustering (Unsupervised Learning)

## Project Overview

This project demonstrates the application of the K-Means clustering algorithm to the Iris dataset as part of the Codveda Technologies Data Science Internship.

The objective is to identify natural groupings within the dataset without using the class labels during model training. The optimal number of clusters is determined using both the Elbow Method and the Silhouette Score. Principal Component Analysis (PCA) is used to visualize the resulting clusters in two-dimensional space.

---

## Objectives

- Apply K-Means clustering to the Iris dataset.
- Determine the optimal number of clusters using the Elbow Method.
- Validate the selected number of clusters using the Silhouette Score.
- Reduce dimensionality using PCA.
- Visualize the discovered clusters and cluster centroids.
- Interpret clustering results.

## Results

- The Elbow Method suggested **3 clusters** as the optimal solution.
- The Silhouette Score provided additional insight into cluster separation.
- PCA clearly visualized three meaningful clusters.
- The K-Means algorithm successfully identified natural groupings within the Iris dataset.
